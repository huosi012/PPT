# 参访点位图片清单（二～八，每处 3 张）

> 对应文件：`20261108学员手册2_点位修改版.docx` 中的"三、参访点位介绍"
> 手册里每个点位下都留了 3 格灰色虚线占位框，找到图片后，删掉框里的文字，直接把图片插进格子里就行。

**统一要求**
- 横版照片（比例 3:2 或 16:9），长边 ≥ 1920 像素，最低也不要小于 1080 像素
- 要原图：不要截图，不要带水印、字幕或二维码
- 新闻网站的图片一般都写着"未经授权不得转载"，正式印刷前最好请各点位提供官方宣传图，或者确认能用
- 文件名建议写成：`序号-点位-图号`，例如 `05-上海硅巷-1.jpg`
