# 图示：选择、重画与校核

## 选图原则
- 先做“原图 ↔ 新图”对照表：内容重复 → 用新图替换原图位置；没有新图对应 → 保留原图；实拍照片、真实图纸 → 保留（重画会失真），除非用户点名要重画示意版。
- 图放在它说明的文字旁边（例：投影对应关系图放在“俯、左视图宽相等”之后）；嵌入式，不浮动；宽度不超过单元格可用宽度 `(tcW - 左右边距 - 40) × 635 EMU`。
- 图注：16 半磅、灰色、居中；原文有图号的沿用“图2-2a …”。
- 值得补图的地方：纯文字解释空间/方位关系的段落（如“方位对应关系”）、知识总结（知识框架链）、学习内容三步（缩略图）、重点/难点（左文右图）。不要画没有数据支撑的统计图（如学情雷达图）。

## 画法（SVG → PNG）
- 用 Python 生成 SVG，`sharp` 渲染 PNG（density 144–200）。字体 `Noto Sans CJK SC, Microsoft YaHei`。
- 配色与文档一致：藏蓝 `1F3864`、青绿 `2E7D7B`、金 `C9A227/A8841A`；V 面 `E8EEF7`、H 面 `FBF3DC`、W 面 `E3F1EF`；投影/强调红 `C0392B`（仅投影结果）。
- 立体图用等轴测：`x → 左下，y → 右下，z → 上`，观察方向 (1,1,1)。多面体面按外法线与 (1,1,1) 点积 > 0 取可见面，再按质心 x+y+z 由远到近绘制（Newell 法向量 + 朝外判定），否则会画出“缺面”的盒子。
- 参考实现：`scripts/reference_jiaoan3/draw.py`（三投影面体系、展开、三视图、正/斜投影、单面投影不唯一）、`draw2.py`（直角弯板、中心投影与正投影、课本搭建三面体系）。

## 校核清单（每张图都过一遍）
- 三视图：长对正（主/俯同长）、高平齐（主/左同高）、宽相等（俯/左同宽）；分界线位置与形体一致。
- 方位：俯、左视图“靠近主视图一侧为后，远离为前”；主视方向箭头指向前面。
- 形体特征位置与原图一致（例：直角弯板方槽在底板左端、开口朝左、贯通；切角在竖板顶部前侧），并与原三视图互相印证。
- 结论文字正确（例：平行于投影面的平面在斜投影下也反映实形——不要写“形状大小变化”）。
- 标注不遮挡线条、箭头不与直角符号等重叠（正投影把箭头放在投射线中段，直角符号画在交点处）、画布不裁字（底部留足边距）。
