# PPT

《7.3 轨道交通装备性能验证的多智能体协同运行与调度引擎技术研究》课题申报汇报 PPT。

| 文件 | 说明 |
|:---|:---|
| `项目汇报PPT.pptx` | 成品 PPT（19 页，16:9，可直接编辑；每页“备注（讲稿）”在备注栏） |
| `项目汇报PPT文本.md` | 文本稿 v11（与 PPT 同步；顶部有修订说明与评审要点对照表） |
| `preview/` | 各页预览图（LibreOffice 渲染，字体为近似替代，仅供快速浏览） |
| `tools/build_deck.py` | 生成脚本：逐页版式与内容 |
| `tools/pptkit.py` | 版式组件库：页框、卡片、面板、结论条、表格、KPI、标尺、附图等 |
| `tools/deck_components.py` | 页级组件：场景条、要点卡、大数字、目标占位、附图组合与占位框 |
| `assets/` | 图标（Tabler Icons，MIT）与机车插画 |

## 版式与风格

- 页眉按单位模板：常规字重大标题（页面主题）＋红色渐变横幅（白字写本页结论，细红边框）；页脚只留右下角页码；封面、结束页保持原版式。
- 正文区在横幅以下、页码以上（y 328—1000，1920×1080 画布）；各页正文底边统一对齐到 1000。
- 正文 3—5 条要点，细节写在备注栏；研究内容页以“现状与问题”开头，结合实际工程场景讲研究内容。
- 信息密度：投影全篇约 5700 字（内容页平均约 300 字）；同一信息只在一页展开（使用流程在第 11 页、知识产权方向在第 18 页、阶段起止在第 13 页），其余页只引一句或放进备注。
- 配色统一为模板主红 `#C00000`（横幅细边框 `#EE3026`），红色只做点缀；中性色为干净灰，线条与底色浅、色条细；四层架构、四个阶段、预算条用同一红系由浅到深。
- 色块布局：每页只有一个红色焦点（当前项、本课题、结论条），其余卡片一律白底细边＋3px 色线；淡红底只用于结论与当前项，灰底只用于附图面板与合计行，深灰实心块只用于“项目负责人”标签，暖黄只用于【待填】。
- 字体：`微软雅黑`（正文/标题）、`Consolas`（编号/页码/数字）。
- 各页按内容选用不同版式：三个数字＋案例、三环节对比卡、四层路线、场景条＋要点卡＋示意图、甘特＋考题表、KPI 等。

## 重新生成

```bash
pip install python-pptx pillow lxml
python3 tools/build_deck.py            # 输出 项目汇报PPT.pptx（默认配色 premium）
PPT_PALETTE=formal python3 tools/build_deck.py out.pptx   # 切换配色：premium（模板主红，默认）/ formal（稳重蓝）/ muted（低饱和多色）/ vivid（参考页原色）
```

图标 PNG 已随仓库提供；如需新增图标，先在 `tools/` 下执行 `npm install`（依赖 `@tabler/icons`、`sharp`）。
