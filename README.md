# PPT

《7.3 轨道交通装备性能验证的多智能体协同运行与调度引擎技术研究》课题申报汇报 PPT。

| 文件 | 说明 |
|:---|:---|
| `项目汇报PPT.pptx` | 成品 PPT（25 页，16:9，可直接编辑） |
| `项目汇报PPT文本.md` | 文本稿（PPT 内容来源） |
| `preview/` | 各页预览图（LibreOffice 渲染，字体为近似替代，仅供快速浏览） |
| `tools/build_deck.py` | 生成脚本：逐页版式与内容 |
| `tools/pptkit.py` | 版式组件库：页框、问题卡、色条面板、结论条、红条总结、阶段卡、虚线分区、标尺等 |
| `assets/` | 图标（Tabler Icons，MIT）与机车插画 |

## 版式与风格

- 白底、左上大标题（“关键词：结论句”）＋ 红色短条 ＋ 灰色副标题；页脚为“主题 | 汇报类型 | 章节”与页码。
- 色彩：深墨 `#0F1A2B` 为主，品牌红 `#C00000` 为唯一强调色；模块色按四层架构固定——①基础层橙、②决策层蓝、③执行层紫、④集成层绿。
- 字体：`微软雅黑`（正文/标题）、`Consolas`（编号/页码/数字）。
- 各页按内容选用不同版式：闭环页、四栏卡片、架构图＋阶段卡、执行链、甘特进度、对比表、KPI、组织架构等。

## 待补充内容

## 重新生成

```bash
pip install python-pptx pillow
python3 tools/build_deck.py            # 输出 项目汇报PPT.pptx
PPT_PALETTE=formal python3 tools/build_deck.py out.pptx   # 切换配色：vivid（现版，默认）/ formal（稳重蓝）/ muted（低饱和多色）
```

图标 PNG 已随仓库提供；如需新增图标，先在 `tools/` 下执行 `npm install`（依赖 `@tabler/icons`、`sharp`）。
