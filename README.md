# PPT

《7.3 轨道交通装备性能验证的多智能体协同运行与调度引擎技术研究》课题申报汇报 PPT。

| 文件 | 说明 |
|:---|:---|
| `项目汇报PPT.pptx` | 成品 PPT（21 页，16:9，可直接编辑；每页“备注（讲稿）”在备注栏） |
| `项目汇报PPT文本.md` | 文本稿 v6（PPT 内容来源；顶部有修订说明与评审要点对照表） |
| `preview/` | 各页预览图（LibreOffice 渲染，字体为近似替代，仅供快速浏览） |
| `tools/build_deck.py` | 生成脚本：逐页版式与内容 |
| `tools/pptkit.py` | 版式组件库：页框、卡片、面板、结论条、表格、KPI、标尺、附图等 |
| `tools/deck_components.py` | 页级组件：场景条、要点卡、大数字、目标占位、附图组合与占位框 |
| `assets/` | 图标（Tabler Icons，MIT）与机车插画 |

## 版式与风格

- 每页标题即结论，正文 3—5 条要点，细节写在备注栏；关键页以“现状与问题”开头，结合实际工程场景讲研究内容。
- 配色“主红·留白”：深绛红 `#A61C22` 为主色，只做点缀；中性色为不带黄调的干净灰，线条与底色浅、色条细；四层架构、四个阶段用同一红色阶由浅到深。
- 字体：`微软雅黑`（正文/标题）、`Consolas`（编号/页码/数字）。
- 各页按内容选用不同版式：三个数字＋案例、三步流程＋对比表、四层路线、场景条＋要点卡＋示意图、甘特＋考题表、KPI 等。

## 附图与待填

- 第 8—11 页示意图为形状组合（命名“附图 · ××”），选中整组删除即可替换为实际图片；第 20 页成果 1—3 为附图预留位置。
- 机车插画由课题组自行替换（`assets/illustrations/`）。
- 【待填】（暖黄虚线框）：第 6 页软件迭代频率；第 10 页防冻限值；第 14、16 页目标值；第 17 页人员费人月与标准；第 19 页团队基础。
- 文本稿中的 `****`、`***` 等脱敏占位原样保留，请替换为实际名称。

## 重新生成

```bash
pip install python-pptx pillow lxml
python3 tools/build_deck.py            # 输出 项目汇报PPT.pptx（默认配色 premium）
PPT_PALETTE=formal python3 tools/build_deck.py out.pptx   # 切换配色：premium（主红·留白，默认）/ formal（稳重蓝）/ muted（低饱和多色）/ vivid（参考页原色）
```

图标 PNG 已随仓库提供；如需新增图标，先在 `tools/` 下执行 `npm install`（依赖 `@tabler/icons`、`sharp`）。
